# denmark_regions.geojson

The five Danish regions (DK-81 Nordjylland, DK-82 Midtjylland, DK-83 Syddanmark,
DK-84 Hovedstaden, DK-85 Sjælland), simplified geometry, from geoBoundaries
(gbOpen DNK ADM1, release 9469f09; source: Web Vectors Map, year represented
2021). Licence: CC BY 4.0. Cite: Runfola et al. (2020) geoBoundaries: A global
database of political administrative boundaries. PLoS ONE 15(4): e0231866.
Used only to draw the regional performance figure.
