## Clinical construction in this refreshed candidate

Newly generated clinical recipes now request **cohort-size-matched strata**.
This is a baseline-only rank benchmark, using native category sizes and the
model’s predictions in the same eligible evaluation population. Ties are kept
together. These strata compare survival at similar group sizes. They are not
fixed individual classification thresholds.

The low-risk expansion question uses a separate development KM-matched numeric
cutoff. The high-risk detection question uses a separate development specificity
cutoff. These cutoffs are frozen before evaluation. Achieved evaluation survival
and specificity must be reported, even if they differ from development targets.
There is no forced K-category partition between two incompatible anchors.
Recall, precision, MCC, specificity and confusion counts remain exported at
the declared boundaries/anchors. The new count intervals condition on the
fitted development thresholds and weights, with paired patient resampling.

This changes future generated rehearsal recipes. Already running processes and
existing recipes have not been modified on the server. This remains a tuning
candidate for author audit before the final test analysis is locked.

## Numerical interpretation preserved

- Historical headline point differences can be reconstructed on intersected
  cell keys when a direct contrast was not exported. Their descriptive IQR is
  labelled accordingly. Confidence intervals are never obtained by adding or
  subtracting separate intervals. New direct contrasts are registered for a
  subsequent prediction analysis.
- Small source-removal effects remain small. Neither gate allocation nor a
  visually strong arrow establishes donor benefit. The frozen mechanism audit
  must distinguish global correction, own-task signal, borrowed sources and
  gate adaptation in the same fitted model.
- Whole-cohort AUC uses common patients for model comparison. Coverage is shown
  beside it. Predictions from unavailable disease-specific XGBoost fits are not
  silently removed only from the neural comparator or interpreted as zeros.
- Cell counts and support sensitivity describe their declared finite rosters.
  An interval crossing zero does not establish equivalence or absence of harm.

of the revised schematics and mechanism sensitivity. Automated text/legend

These checks support this set of artwork. They cannot guarantee a layout for
