## Order of work

1. Add GPUs (`WAIT=1 bash scripts/paper_gpu_worker.sh` per allocation); check disk.
2. Sync code. Then CPU, in parallel:
   - `features` (writes matched and registry-augmented matrices), then `tabular`
     sharded, then `tabular --registry` sharded;
   - `cell-metadata`;
   - `table1 --inspect-inputs --execute`, then `table1 --execute`: writes
     `table1/manuscript/table1_current_review.tex` (+ `_by_disease.tex`), rendered on
     the server with counts of 1-4 as <5. Compile, PI sign-off, then copy the two .tex
     files to `paper/tables/` (rename to `table1_current_approved.tex` once approved);
   - scores: `compute_prognostic_scores`, merge into the clinical table, then `patient-metadata`.
3. National encoder: `external-data` (filter national MEDS to our patients, tokenise with the PHAIR
   vocabulary, audit coverage and [UNK]), then `export-external`, then `dapt` (one GPU).
4. Router screens as fits finish: source → rank → query → lock; then
   `prepare --stage 2 --include-external`; restart workers.
5. Before held-out: lock primary metric, margins, priors, router-null
   tolerance; fill the score config (`outcome`, provenance, `manuscript.index`).
6. After training: evaluate tuning → lock → held-out → inventory → analyse →
   Bayes → plot/embedding tables → figures → clinical scores → results text.
